# mars-probe-simulation
I needed a simulation that's also open source, so I made it.

The index.html is the same simulation rewritten in JavaScript. You can run it and change distances, speed and direction of approach, and the viewer will animate the result. It's a fun demonstration of Kepler's laws.

To read the "meat" of the program in the classroom, you can either open the html file directly and pore through the code, or take a look in the Python file, which is somewhat more human readable and has notes about the coding and the physics interspersed thhroughout. The <a href="https://en.wikipedia.org/wiki/Euler_method">Euler algorithm</a> isn't perfect, and there will be an error in comparison to analytical methods and real-life physics. That is because I deliberately chose an algorithm that is the easiest for kids to understand, rather than a more robust one (like <a href="https://en.wikipedia.org/wiki/Leapfrog_integration">Leapfrog</a>) with smaller errors which would be harder to comprehend.

If you're a teacher unaware of how Jupyter notebooks work, they're basically rich text files, where you can weave code through textual information and pictures. By far, it is the easiest way to make hands-on code practice. You have two options: use Jupyter Lite at https://jupyter.org/try-jupyter/lab/ or you can try Colab. Jupyter Lite doesn't require a login, but it's not tablet or phone friendly and every student needs to sit at a computer. Google Colab makes the notebook easier to distribute, but (even though it's made by Google) it's considered an external application and you have to have it explicitly allowed by your administrator beforehand. In case you go the Colab way, do not be deterred by its shaking of fists about the limited amount of calculation you get: it's about 80 hours at the time of writing (June 2024), and given that each run-through of the notebook takes less than 2 seconds, you should be fine. Or you can install Jupyter Lab and Jupyter Notebook locally on your school computers in VS Code, but that seems like an overkill unless you plan to use that tool on a regular basis.
